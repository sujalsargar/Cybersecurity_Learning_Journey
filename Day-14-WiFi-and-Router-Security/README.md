Day 14 - Wi-Fi and Router Security
Objective

Understand how Wi-Fi and routers work, learn why securing a home network is important, and explore common attacks that target wireless networks.

Lesson of the Day

Today, I learned that my Wi-Fi router is the front door to my digital life.

Every website I visit, every app I use, every login, and every message I send passes through my router before reaching the internet.

One important lesson was that many people never change the router's default settings or update its firmware, which can leave their home network vulnerable.

Why the Router is Important

A router does much more than simply provide Wi-Fi.

It is responsible for connecting devices to the internet and protecting the home network.

The Three Main Jobs of a Router
1. Network Gateway
Connects the home network to the internet.
Routes data between devices and external servers.
2. Security Boundary
Acts as the first line of defense.
Filters network traffic using firewall features.
Helps prevent unauthorized access.
3. Software Device
Runs firmware that controls its features.
Requires regular updates to fix bugs and security vulnerabilities.
What a Router Does

A modern router performs several important tasks:

Connects your home to the internet.
Assigns IP addresses to devices using DHCP.
Handles DNS requests.
Runs a firewall to help protect the network.
Broadcasts the Wi-Fi network.
Two Important Passwords
1. Wi-Fi Password

This password allows devices to connect to the wireless network.

A strong, unique password helps prevent unauthorized users from accessing the network.

2. Router Admin Password

This password protects the router's management interface.

If attackers obtain this password, they may be able to:

Change DNS settings.
View connected devices.
Modify security settings.
Control the entire network.

Changing the default administrator password is an important security practice.

Wi-Fi Security Protocols

Wireless security has improved over time.

WEP (1997)
First Wi-Fi security standard.
Now considered insecure.
WPA (2003)
Improved security over WEP.
Introduced stronger encryption.
WPA2 (2004)
Became the industry standard for many years.
Provides significantly stronger protection than earlier versions.
WPA3 (2018)
Latest Wi-Fi security standard.
Offers stronger authentication and improved protection against password guessing attacks.
KRACK Attack

I also learned about the KRACK (Key Reinstallation Attack).

KRACK targets the WPA2 four-way handshake by tricking a device into reinstalling an encryption key.

This can allow attackers to:

Decrypt some Wi-Fi traffic.
Spy on network communication.
Inject or modify certain data under specific conditions.

Keeping devices updated helps protect against this vulnerability.

Other Wi-Fi Threats
Evil Twin Network

An attacker creates a fake Wi-Fi network with a name similar to a legitimate one.

If users connect to it, the attacker may intercept their traffic or steal information.

DNS Manipulation

Attackers modify DNS settings to redirect users to malicious or fake websites.

Malicious Captive Portal

A fake login page is presented when connecting to a Wi-Fi network to trick users into entering credentials or installing malware.

Metadata Surveillance

Even when traffic is encrypted, attackers may still observe metadata such as:

Which websites are contacted.
Connection times.
Device activity.
Communication patterns.
What I Learned
A router is much more than a device that provides Wi-Fi.
Routers connect, manage, and help protect home networks.
Changing default passwords is an important security measure.
Firmware updates help fix security vulnerabilities.
WPA3 is currently the strongest widely available Wi-Fi security protocol.
Public Wi-Fi networks can introduce several security risks.
Key Takeaways

✅ Secure both the Wi-Fi password and the router admin password.

✅ Keep router firmware up to date.

✅ Use WPA3 whenever available (or WPA2 if WPA3 is not supported).

✅ Avoid connecting to unknown or suspicious Wi-Fi networks.

✅ Stay alert for attacks such as Evil Twin networks, DNS manipulation, malicious captive portals, and KRACK.

Reflection

Today's lesson helped me understand that securing my home network is just as important as securing my computer. The router is responsible for managing all internet traffic entering and leaving the network, making it a critical part of cybersecurity.

I also realized that simple actions—such as changing default passwords, updating firmware, and using strong Wi-Fi security—can greatly improve the security of a home network.
