Day 47 - Setting Up Linux
Objective

Learn the different ways to install and run Linux, understand the advantages of each method, and choose the most suitable setup for learning cybersecurity.

Lesson of the Day

Today, I learned about the different ways to set up and run Linux.

Before using Linux for cybersecurity, it is important to decide how you want to install and access it. There are several methods, each designed for different needs and experience levels.

A simple way to remember today's lesson is:

There is no single "best" way to run Linux—the right choice depends on your learning goals and your computer.

Why Set Up Linux?

Linux is widely used in cybersecurity because many security tools, servers, and cloud environments run on it.

Setting up Linux allows us to:

Practice Linux commands.
Use cybersecurity tools.
Learn system administration.
Build hands-on experience in a safe environment.
Ways to Run Linux

Today's lesson introduced four common methods of running Linux.

1. Windows Subsystem for Linux (WSL)

Windows Subsystem for Linux (WSL) allows Linux to run directly inside Windows without replacing the Windows operating system.

Advantages
Easy to install.
No need to partition the hard drive.
Linux and Windows can be used together.
Ideal for learning Linux commands and development.
Best For
Beginners
Developers
Cybersecurity students using Windows
2. Virtual Machines (VMs)

A Virtual Machine (VM) allows Linux to run inside a virtual computer while Windows remains the main operating system.

Popular virtualization software includes:

Oracle VirtualBox
VMware Workstation
Advantages
Safe testing environment.
Easy to create snapshots and restore the system.
Multiple operating systems can run on one computer.
Excellent for cybersecurity labs.
Best For
Cybersecurity practice
Penetration testing labs
Learning Linux without affecting the main operating system
3. Cloud and Online Options

Linux can also run on cloud platforms or online environments.

These provide remote Linux systems that can be accessed through a web browser or SSH.

Advantages
No installation required.
Accessible from anywhere.
Useful for cloud computing and remote administration practice.
Best For
Cloud learning
Remote Linux practice
Lightweight systems
4. Dual Boot or Full Installation

Linux can be installed directly on the computer alongside Windows (Dual Boot) or as the only operating system (Full Installation).

Advantages
Full hardware performance.
Direct access to all system resources.
Best overall Linux experience.
Considerations
Requires disk partitioning.
Installation should be performed carefully.
Switching between Windows and Linux requires restarting the computer.
Best For
Advanced users
Daily Linux users
Long-term Linux environments
Choosing the Right Setup

Each installation method has different strengths.

Method	Best For
WSL	Learning Linux commands on Windows
Virtual Machine	Cybersecurity labs and safe experimentation
Cloud/Online	Remote access and cloud learning
Dual Boot / Full Installation	Full Linux experience and maximum performance

There is no single correct choice—each option is useful depending on your requirements.

Why Virtual Machines Are Popular in Cybersecurity

One of the biggest advantages of Virtual Machines is safety.

If something goes wrong during practice:

The virtual machine can be reset.
Snapshots can restore previous states.
The host operating system remains unaffected.

This makes VMs ideal for learning cybersecurity tools and performing experiments.

What I Learned
Linux can be installed in multiple ways.
WSL allows Linux to run inside Windows.
Virtual Machines provide isolated environments for practice.
Cloud platforms offer remote Linux systems.
Dual Boot provides a complete Linux experience.
Choosing the right setup depends on learning goals and system requirements.
Key Takeaways

✅ Linux can be run without replacing Windows.

✅ WSL is beginner-friendly and easy to set up.

✅ Virtual Machines are ideal for cybersecurity practice.

✅ Cloud environments allow Linux access without installation.

✅ Dual Boot provides maximum performance but requires careful installation.

Reflection

Today's lesson helped me understand that learning Linux does not require replacing my existing operating system.

I learned several ways to access Linux, each with its own advantages. Whether using WSL, a Virtual Machine, cloud environments, or a full installation, the important part is gaining hands-on experience.

For cybersecurity learners, Virtual Machines and WSL provide safe and flexible environments for practicing Linux commands and security tools without affecting the primary operating system.

My biggest takeaway is:

The best way to learn Linux is the one that lets you practice consistently and safely.
