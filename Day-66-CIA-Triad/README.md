Day 66 - The CIA Triad
Objective

Understand the CIA Triad, the foundation of information security, and learn how confidentiality, integrity, and availability help cybersecurity professionals understand risks and choose appropriate security controls.

Lesson of the Day

Today, I learned about the CIA Triad, one of the fundamental concepts in cybersecurity.

CIA stands for:

Confidentiality – Keeping information secret.
Integrity – Keeping information accurate and trustworthy.
Availability – Making sure information and systems are accessible when needed.

A simple way to remember it is:

Confidentiality = Secret
Integrity = Accurate
Availability = Accessible

1. Confidentiality

Confidentiality means preventing unauthorized people from accessing information.

The goal is to make sure that sensitive information is only available to authorized users.

Examples of controls that support confidentiality:

Passwords
Authentication
File permissions
Encryption
Access control
Firewalls
Example

If an attacker steals a private document and unauthorized people can read it, confidentiality has been compromised.

2. Integrity

Integrity means keeping information accurate, complete, and trustworthy.

The goal is to prevent unauthorized modification or destruction of data.

Examples of controls that support integrity:

File permissions
Hashing
Access controls
Monitoring and logs
Backups
Security controls
Example

If an attacker changes the contents of an important file without authorization, integrity has been compromised.

3. Availability

Availability means making sure systems and information are accessible when authorized users need them.

Examples of controls that support availability:

Backups
Redundancy
Monitoring
System maintenance
Software updates
Disaster recovery
Protection against denial-of-service attacks
Example

If a company's website becomes unavailable because of a DDoS attack, availability has been compromised.

How Security Professionals Think

Whenever a security professional sees a risk or attack, they can ask three important questions:

1. What is being attacked?

Identify the system, information, account, or resource at risk.

2. Which CIA property is affected?

Is the attack affecting:

Confidentiality?
Integrity?
Availability?
Or multiple properties?
3. How can we protect it?

Choose appropriate security controls to reduce the risk.

This creates a simple security-thinking process:

Risk / Attack
     ↓
What is being attacked?
     ↓
Which CIA property is affected?
     ↓
What security control can protect it?
CIA Trade-Offs

One important lesson today was that the three CIA goals cannot always be maximized at the same time.

Security is often about finding the right balance between:

Confidentiality
Integrity
Availability
Maximum Confidentiality

If we tried to achieve maximum confidentiality by blocking everyone from accessing a system:

No one can access it
        ↓
Very high confidentiality
        ↓
Very low availability

The system may be extremely protected from unauthorized access, but it would also be useless to legitimate users.

Maximum Availability

If everyone could access everything without restrictions:

Everyone can access it
        ↓
Very high availability
        ↓
Very low confidentiality

The system would be accessible, but sensitive information could easily be exposed.

Therefore, cybersecurity is about finding the appropriate balance.

Other Security Trade-Offs

Security controls can sometimes introduce other problems.

Strong Security vs User Experience

If security requirements are too difficult, users may become frustrated.

For example, overly complicated authentication requirements could encourage users to find insecure shortcuts.

Therefore, security should be strong and practical.

Integrity Checks vs Availability

Heavy integrity checks can consume system resources or slow down operations.

If a system becomes too slow, availability may be affected.

This shows that security decisions often require balancing different goals.

Why the CIA Triad Is Important

The CIA Triad provides a common way to think about security.

It helps cybersecurity professionals:

Understand what security is trying to protect.
Analyze security incidents.
Identify the impact of attacks.
Select appropriate security controls.
Manage cybersecurity risks.
Communicate security concepts clearly.

It also provides a common language for cybersecurity professionals.

CIA in Real-World Attacks

Different attacks can affect different parts of the CIA Triad.

Data Breach

Usually affects:

Confidentiality

because unauthorized people gain access to information.

Data Modification

Usually affects:

Integrity

because information has been changed without authorization.

DDoS Attack

Usually affects:

Availability

because legitimate users cannot access the service.

Some attacks can affect more than one property at the same time.
